# Strategy 003 — Economic Execution Viability Protocol

**Status:** 🟢 Protected prediction gate passed; economic execution test frozen.

## 1. Frozen economic question

The predictive gate has passed. The next question is not whether we can find a better signal; it is whether the **already-frozen protected-validation signal** can be translated into executable economics under a concrete, pre-registered portfolio and cost model.

The economic test uses only the protected-validation observations generated by the frozen 003H candidate:

- next 5-minute cross-sectional excess return;
- same 15 eligible equities;
- additive OLS on `close_location_1bar + intraday_position_60bar`;
- training-only standardization;
- protected validation: 2026-06-10 through 2026-08-19;
- final holdout beginning 2026-08-20 remains untouched.

## 2. Frozen portfolio

At every eligible protected-validation timestamp:

- rank the 15 equities by the frozen prediction;
- long Q5 = 3 stocks;
- short Q1 = 3 stocks;
- equal notional within each side;
- 50% gross notional long and 50% gross notional short;
- net exposure 0%;
- hold one 5-minute bar;
- rebalance on every eligible signal timestamp;
- close any remaining positions after the final signal timestamp;
- no leverage, thresholds, symbol filters, time-of-day filters, volatility scaling, or holding-period search;
- no overnight positions.

The validated target is close(t) to close(t+1), so the implementation is a **close-to-close execution proxy**, not an assertion that a real order receives the recorded close.

## 3. Portfolio notional

Brokerage is charged per executed order, so the test must use **real rupee notional**, not normalized unit weights.

Default reported size: **₹1,00,000 gross portfolio notional**.

The portfolio notional is a capital-scale input; it does not change rankings, weights, holding period, or signal selection. The runner may be repeated at other pre-declared sizes for sensitivity, but a size should not be chosen after observing results because it creates a favorable cost result.

The economic record must clearly distinguish:

- gross portfolio return (%);
- rupee gross P&L at the selected notional;
- statutory/broker cost in rupees and bps;
- additional spread/slippage/impact cost;
- net return after all costs.

## 4. Turnover

The theoretical fully refreshed one-bar portfolio has 2.0× gross turnover for entry + exit. However, the implementation must calculate **actual position-change turnover** because a stock can remain in the same portfolio across adjacent timestamps.

Turnover is:

```
sum(abs(current_weight_i - previous_weight_i)) × portfolio_notional
```

with the final portfolio explicitly closed after the last signal.

This prevents overcharging costs when names persist and avoids assuming that every timestamp creates six new buys plus six new sells.

## 5. Fee model

Use the current published Zerodha NSE equity intraday schedule:

- brokerage: ₹20 or 0.03%, whichever is lower, per executed order;
- STT: 0.025% on sell turnover;
- NSE transaction charge: 0.00307% on buy + sell turnover;
- stamp duty: 0.003% on buy turnover;
- SEBI turnover fee: ₹10/crore;
- GST: 18% on brokerage + transaction charges + SEBI charges.

Zerodha currently publishes these rates on its charges page. citeturn489292search0

## 6. Frozen execution-friction scenarios

| Scenario | Spread/slippage per side | Impact per side |
|---|---:|---:|
| Fee floor | 0 bps | 0 bps |
| Low | 0.5 bps | 0.5 bps |
| Base | 1.0 bps | 0.5 bps |
| Stress | 2.0 bps | 1.0 bps |

The same scenario values are applied to **actual executed turnover** and are not calibrated after seeing results.

These are scenario assumptions, not measured historical fill costs.

## 7. Late-session / closing-auction flag

NSE currently states that the Closing Auction Session for applicable cash-segment securities runs from **15:15 to 15:35**, while non-CAS continuous trading runs to 15:30. citeturn489292search1turn489292search5

Because the frozen signal scores late in the session, the runner must flag signal timestamps at/after 15:15 as potentially entering the closing-auction regime. These observations must not be silently removed after results are observed.

The flag is a diagnostic only in this first economic test; the runner does not silently alter the portfolio rule based on it.

## 8. Short-side feasibility

The portfolio contains short positions. SEBI's framework permits short selling by retail and institutional investors subject to the applicable framework, while naked short selling is not permitted. citeturn489292search36

This means the economic result is still a **theoretical executable baseline** until stock borrow/SLB availability and broker-specific short-sale mechanics are verified for every short position.

## 9. Decision gate

- If gross economics remain positive after the fee floor and the predefined base scenario, the current form advances to prospective paper/shadow testing.
- If the predictive relationship survives but fee-floor/base economics eliminate the executable edge, close the current Strategy 003 executable line.
- If results are materially ambiguous, record ambiguity and stop.

The decision is made on the frozen scenarios; no scenario, notional, turnover rule, or portfolio rule may be changed after results are observed.

## 10. Evidence boundary

The runner reads only the protected-validation scored observations. It hard-rejects any observation on/after 2026-08-20. The final holdout is therefore not used by this experiment.
