# Quant Research Strategies

This repository contains my quantitative research work in Python.

I document each strategy from the first question I asked, through the tests I ran, to the conclusion I reached. The purpose is to make the research easy to follow and to show why each step led to the next one.

## Research approach

The strategy documents follow the actual order of the research:

**Question → data → first test → interpretation → next question → deeper test → validation → trading check → conclusion**

I use statistical and quantitative methods where they answer a specific research question. Terms such as **z-score, residual, stationarity, OLS, Ridge regression, Information Coefficient (IC), walk-forward validation, out-of-sample testing, turnover, and transaction costs** are explained in the strategy documents where they are used.

The repository is intentionally kept focused so that the research story is easier to read.
